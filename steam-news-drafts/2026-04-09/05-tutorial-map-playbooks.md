# Map-specific tutorial playbooks and onboarding flow

## Hover Info
Tutorial onboarding now changes with the map, teaching different economy and logistics paths instead of one generic lesson.

## Short Description
The tutorial now branches by map type, with dedicated playbooks for Desert, Grasslands, and Islands so new players learn the economy, logistics, and production flow that actually fits the terrain they are playing on.

## Steam News Draft
The campaign tutorial is no longer a one-size-fits-all intro.

Players can now choose a map-specific tutorial flow for Desert, Grasslands, or Islands, and each version teaches the economy and logistics path that actually matters on that terrain. That means Oil Seeker scouting, Dock timing, Construction Ship usage, Oil Wells, and Oil Rigs are now taught in the right context instead of being buried inside a generic opening.

This makes onboarding more practical, more readable, and much better aligned with how real matches actually play out.

Highlights in this update:
- Added a tutorial map picker with Desert, Grasslands, and Islands variants.
- Reworked tutorial objectives around terrain-specific economy and logistics.
- Added clearer placement guidance for gold, land oil, offshore oil, land, and water.
- Tutorial flow now teaches what matters for the selected map instead of a generic script.
